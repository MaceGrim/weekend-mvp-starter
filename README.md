# Weekend MVP Starter

A small request tracker you can adapt into one testable business workflow. It uses only three source files: `index.html` for structure, `styles.css` for appearance, and `app.js` for behavior and browser storage.

## Quick start

1. Create your repository with **Use this template** on GitHub.
2. Open it with GitHub Desktop and choose a local folder.
3. In the ChatGPT desktop app, select Codex and open that folder.
4. Ask Codex to make one focused change.
5. Open `index.html` in a browser to preview.
6. Test the primary workflow, review the changed files, commit a known-good version, and push it with GitHub Desktop.

The app works without a build step and saves records in this browser with `localStorage`. Export JSON before clearing browser data or moving computers.
