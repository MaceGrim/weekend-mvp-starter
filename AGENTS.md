# Codex Instructions

This static project is used in a beginner entrepreneurship workshop.

- Inspect the project and briefly restate scope before editing.
- Prefer focused edits over rewrites; say which files are likely to change.
- Preserve semantic HTML, plain CSS, plain JavaScript, relative paths, responsive behavior, accessibility, and local/GitHub Pages preview.
- Do not add dependencies, frameworks, build tools, authentication, payments, databases, external APIs, analytics, cookies, secrets, or real customer data.
- Use fictional sample data only.
- When a request is broad, propose a smaller testable workflow.
- Preserve and retest create, edit, delete, search, filter, persistence, import, export, and reset after meaningful changes.
- Explain significant changes plainly and give exact preview/test steps.
- Warn when a request introduces production, privacy, legal, or security concerns.
